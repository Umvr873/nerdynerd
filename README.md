# A Garden Grown For You

A completely fresh, garden-and-dusk themed version of the love app — new palette, new mechanics, new writing throughout, distinct from any earlier version.

## What changed from before
- Theme: warm dusk garden (terracotta / sage / gold) instead of space/aurora
- "Catch the stars" -> "Catch the Fireflies"
- "Open When Letters" -> "Postcards on the Line"
- "Reasons You Shine" -> "Sunbeams"
- "Memory Lane" -> "Growth Rings"
- "Secret Room" -> "The Greenhouse"
- "Love Coupons" -> "Seed Packets"
- All poems, reasons, letters, quiz questions, and messages rewritten from scratch

## Personalize
Open `script.js` and edit the `CONFIG` object at the top — her name, your name, the secret unlock words, poems, letters, quiz, and the final message.

## Use it
Just open `index.html` in a browser. No build step, no dependencies beyond Google Fonts.
